# Proposal

## Why

작은 창은 3D 캐릭터를 늘 보여 주는 창인데, 지금은 열 때만 자리를 잡고 그 뒤의 변화는 처리하지 않습니다. macOS에서 다른 앱을 전체 화면으로 쓰거나 데스크톱(Spaces)을 바꾸면 작은 창이 보이지 않습니다. 작은 창이 있던 모니터를 빼거나 해상도나 배치가 바뀌어도 창이 화면 밖에 남아 다시 찾을 수 없습니다.

## What Changes

- 작은 창은 어떤 상황에서도 다른 앱 창보다 앞에 보입니다. 다른 앱 창을 누르거나 그 창이 포커스를 가져가도 작은 창은 그 위에 남습니다(macOS, Windows 모두). 지금도 일반 창 위에는 뜨므로 이 동작은 유지합니다.
- 여기에 더해 macOS에서는 모든 데스크톱(Spaces)과 다른 앱의 전체 화면 위에서도 작은 창이 앞에 보입니다. 창 레벨은 일반 항상 위(floating)이고, 메뉴 막대와 알림 같은 시스템 UI는 가리지 않습니다.
- 작은 창이 있던 모니터가 빠지거나 해상도, 배율, 배치가 바뀌어 창이 보이는 화면을 벗어나면, 남은 모니터의 작업 영역 오른쪽 아래 구석으로 옮깁니다.
- 앱을 다시 불러낼 때(macOS 독 아이콘 클릭, 앱 다시 실행) 작은 창이 보이는 화면을 벗어나 있으면 보이는 곳으로 옮긴 뒤 보여 줍니다.
- Windows의 항상 위 동작은 지금과 같습니다. 전용 전체 화면(exclusive fullscreen) 앱 위에 뜨는 것은 OS가 막으므로 이번 범위에 넣지 않습니다.

## Capabilities

### New Capabilities

없음

### Modified Capabilities

- `window`: 작은 창의 항상 위 동작에 macOS 데스크톱과 전체 화면 앱을 넣습니다(FR-WINDOW-001). 다시 불러낼 때 위치를 확인합니다(FR-WINDOW-006). 모니터 구성이 바뀌면 보이는 곳으로 옮기는 요구사항을 새로 추가합니다.

## Impact

- `src-tauri/src/placement.rs`(core): 창이 보이는 화면을 벗어났는지 판정하는 계산과, 옮길 모니터를 고르는 계산이 늘어납니다.
- `src-tauri/src/window/main.rs`, `window/mod.rs`(shell): 작은 창을 만들 때 모든 데스크톱에 보이게 설정하고, 다시 보일 때와 모니터 구성이 바뀔 때 위치를 확인합니다.
- `src-tauri/src/platform/macos.rs`: 전체 화면 앱 위에 뜨게 하는 macOS 창 설정(collection behavior)과 모니터 구성 변경 감지가 들어갈 수 있습니다. `platform/windows.rs`도 모니터 변경 감지에 쓰일 수 있습니다.
- renderer는 바뀌지 않습니다.
