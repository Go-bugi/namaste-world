# Proposal

## Why

앞으로 앱은 로컬에 설치된 Claude Code나 Codex에 질문을 보내야 합니다. 그러려면 어느 에이전트의 어느 모델을 쓸지 먼저 정해야 합니다. 지금 `main` 창에는 템플릿 문구, 데모 3D, 감지 목록, 훅 이벤트 목록이 한데 섞여 있어서 이 선택을 할 자리가 없습니다. 그래서 감지, 훅 설치, 에이전트와 모델 선택 순서로 진행하는 시작 설정 창(`onboarding`)을 따로 둡니다. 나중에 생길 환경설정 창(`settings`)과는 다른 창입니다. 선택이 끝나면 작은 창으로 넘어가서, 이후 기능이 창 여러 개를 띄워도 되는 기반을 만듭니다.

## What Changes

- 지금 `main` 창의 출력 요소 제거: Tauri 템플릿 문구와 링크, 버전 표시, 데모 3D, 감지 결과 목록, 훅 이벤트 목록 **BREAKING**
- 앱을 켜면 시작 설정 창(label `onboarding`)이 열림. 단계는 설치된 에이전트 감지 → 훅 설치 결과 확인 → 사용할 에이전트와 모델 선택이고, "다음" 버튼으로 마칩니다.
- 에이전트 선택지는 감지 결과에서 설치된 것(실행 환경 포함)만 보여 줍니다.
- 모델 선택지는 고른 에이전트의 CLI에서 조회합니다.
  - Claude Code는 프롬프트 없이 초기화 요청만 보내 목록을 받습니다.
  - Codex는 `codex debug models`로 목록을 받습니다.
  - 조회가 실패하거나 5초를 넘기면 앱에 둔 고정 목록을 씁니다.
- "다음"을 누르면 선택을 앱 데이터 폴더에 저장합니다. 다음 실행 때는 저장한 값을 미리 골라 둡니다.
- "다음"을 누르면 시작 설정 창을 닫고 작은 창(label `main`)을 엽니다.
  - 크기는 320×320입니다.
  - 테두리 없이 배경이 투명하고, 항상 위에 뜹니다.
  - 끌어서 옮길 수 있습니다.
  - 시험용 3D 요소를 하나 둡니다.
- 창 위치 처리
  - 작은 창은 시작 설정 창이 있던 모니터의 작업 영역 오른쪽 아래 구석에 엽니다.
  - 모니터 배율(DPI)이 서로 달라도 크기가 맞게 엽니다.
  - 창 전체가 작업 영역(작업 표시줄, 독, 메뉴 막대를 뺀 영역) 안에 들어오게 합니다.
- macOS 투명 배경을 위해 비공개 API를 켭니다. 그래서 macOS 배포는 dmg로만 하고 Mac App Store에는 올리지 않습니다.
- 질문을 실제로 보내는 기능은 이 변경에 넣지 않습니다.

## Capabilities

### New Capabilities

- `start`: 시작 설정 창의 단계 진행, 에이전트와 모델 선택지, 모델 목록 조회, 선택 결과 저장
- `window`: 시작 설정 창에서 작은 창으로 전환, 창 크기와 외형, 여러 모니터와 배율 처리, 창 닫기와 다시 보이기, 끌어 옮기기, 작은 창의 시험용 3D 요소

### Modified Capabilities

- `agent`
  - FR-AGENT-008(감지 결과 목록 화면): `main` 창 대신 시작 설정 창의 감지 단계에 보여 줍니다.
- `hook`
  - FR-HOOK-010(훅 이벤트 목록 화면): 지웁니다. 설치 결과 표시는 새 요구사항 FR-HOOK-015로 옮겨 시작 설정 창에 보여 줍니다.
  - SC-HOOK-002(이벤트 표시 지연): 이벤트 목록 화면이 없어져 지웁니다. 이벤트는 계속 renderer에 전달됩니다.
  - FR-HOOK-011(macOS와 Windows 지원): 지원 대상 요구사항 목록과 "앱 화면에 나온다"는 시나리오를 바뀐 요구사항에 맞춥니다.
  - FR-HOOK-014(앱은 하나만 실행): 다시 실행했을 때 `main` 대신 그때 쓰는 창(시작 설정 창이나 작은 창)을 앞으로 가져옵니다.

## Impact

- `src/renderer`
  - 시작 설정 창 진입점(`onboarding.html`, `windows/onboarding/`)을 추가하고, `windows/main/`은 작은 창으로 바꿉니다.
  - `features/onboarding/`에 시작 설정 흐름을 추가합니다.
  - `features/versions`, `features/hook-events`의 목록 화면, `scene/DemoScene.tsx`를 정리합니다.
  - `vite.config.ts`의 `build.rollupOptions.input`에 새 HTML을 등록합니다.
- `src-tauri`
  - 창을 바꾸는 명령, 모델 목록 조회 명령, 선택을 저장하는 명령을 `commands/`에 둡니다.
  - 모델 목록 조회는 감지처럼 실행 환경(WSL 포함)에서 CLI를 실행합니다.
  - 선택 상태는 `state.rs`에 두고 앱 데이터 폴더에 저장합니다.
  - 모니터와 위치 계산은 로직 모듈에 둡니다. OS별 창 동작은 `platform/`, 창 설정은 `window/`에 둡니다.
  - `tauri.conf.json`에서 `app.windows`를 고치고 `macOSPrivateApi`를 켭니다. 창별 capability 파일(`capabilities/onboarding.json`, `capabilities/main.json`)도 고칩니다.
- 다른 기능
  - 감지와 훅 설치 동작 자체는 그대로입니다.
  - 단일 인스턴스와 macOS 독 아이콘 클릭 동작은 보여 줄 창이 바뀝니다.
