## MODIFIED Requirements

### Requirement: FR-START-002 단계 순서

시작 설정 창은 감지, 훅 설치, 에이전트와 모델 선택, 로그인 확인의 네 단계를 이 순서의 스테퍼로 보여 주어야 한다(SHALL). 한 번에 한 단계의 내용만 보이고, 창이 열리면 감지 단계에서 시작한다. 단계 표시줄에는 네 단계가 모두 나오고, 각 단계가 지금 보고 있는 단계인지, 끝났는지, 아직 시작하지 않았는지가 보인다. 단계는 이전과 다음 버튼(FR-START-005)으로만 옮긴다. 감지 단계는 FR-AGENT-007의 앱 시작 감지 결과를, 훅 설치 단계는 FR-HOOK-007의 설치 결과를 보여 준다.

#### Scenario: 창이 열림

- **WHEN** 시작 설정 창이 열림
- **THEN** 감지 단계의 내용만 보이고, 단계 표시줄에 네 단계가 순서대로 나오며 감지 단계가 지금 단계로 표시된다

#### Scenario: 감지와 설치가 진행 중

- **WHEN** 앱 시작 감지가 아직 끝나지 않음
- **THEN** 단계 표시줄에서 감지 단계는 지금 단계로, 훅 설치, 선택, 로그인 확인 단계는 아직 시작하지 않은 것으로 보인다

#### Scenario: 감지와 설치가 끝남

- **WHEN** 앱 시작 감지와 그 뒤의 훅 설치가 끝났고 사용자가 선택 단계까지 다음 버튼으로 넘어옴
- **THEN** 감지 단계와 훅 설치 단계는 끝난 것으로 보이고, 선택 단계에서 에이전트와 모델을 고를 수 있다

#### Scenario: 감지가 끝나도 자동으로 넘어가지 않음

- **WHEN** 감지 단계에 있는 동안 앱 시작 감지가 끝남
- **THEN** 감지 단계에 그대로 머물고 결과 목록이 보이며, 감지 단계는 끝난 것으로 표시된다

#### Scenario: 다음 단계로 이동

- **WHEN** 감지 단계에서 다음 버튼을 누름
- **THEN** 훅 설치 단계의 내용만 보이고, 단계 표시줄에서 감지 단계는 끝남, 훅 설치 단계는 지금 단계로 표시된다

#### Scenario: 이전 단계로 돌아감

- **WHEN** 로그인 확인 단계에서 이전 버튼을 누름
- **THEN** 에이전트와 모델 선택 단계가 보이고, 앞서 고른 에이전트와 모델이 그대로 골라져 있다

### Requirement: FR-START-005 다음 버튼

시작 설정 창은 지금 단계를 넘어갈 조건이 채워졌을 때만 다음 버튼을, 돌아갈 수 있을 때만 이전 버튼을 활성화해야 한다(SHALL). 비활성화된 버튼은 눌리지 않는다. 다음 버튼의 조건은 감지 단계는 감지나 다시 감지가 진행 중이 아니고 설치됨인 항목이 하나 이상일 때, 훅 설치 단계는 설치가 끝났을 때, 선택 단계는 에이전트와 모델이 모두 골라졌을 때, 로그인 확인 단계는 결과가 로그인됨일 때다. 로그인 확인 단계의 다음 버튼은 FR-START-006의 보관과 작은 창 전환을 하고, 그 처리가 진행 중이면 두 버튼 모두 비활성화된다. 훅 설치(다시 설치 포함)가 진행 중이어도 두 버튼 모두 비활성화된다. 이전 버튼은 감지 단계에서 비활성화된다. 고른 에이전트의 훅 설치가 실패했어도 다음으로 넘어갈 수 있고, 이때 선택 단계에 그 실패가 함께 보인다.

#### Scenario: 감지 중

- **WHEN** 감지 단계에서 앱 시작 감지나 다시 감지가 진행 중임
- **THEN** 다음 버튼과 이전 버튼이 모두 비활성화된다

#### Scenario: 설치된 에이전트가 없음

- **WHEN** 감지가 끝났고 설치됨인 항목이 하나도 없음
- **THEN** 감지 단계의 다음 버튼은 비활성화된다

#### Scenario: 훅 설치 중

- **WHEN** 훅 설치 단계에 있고 설치가 아직 끝나지 않음
- **THEN** 다음 버튼과 이전 버튼이 모두 비활성화되고, 설치가 끝나면 둘 다 활성화된다

#### Scenario: 둘 다 골라짐

- **WHEN** 선택 단계에서 에이전트와 모델이 모두 골라짐
- **THEN** 다음 버튼이 활성화된다

#### Scenario: 모델이 없음

- **WHEN** 선택 단계에서 에이전트는 골랐지만 모델이 골라지지 않음
- **THEN** 다음 버튼은 비활성화된다

#### Scenario: 로그인 안 됨

- **WHEN** 로그인 확인 단계의 결과가 로그인 안 됨이거나 확인 실패이거나 아직 확인 중임
- **THEN** 다음 버튼은 비활성화되고 이전 버튼은 활성화된다

#### Scenario: 로그인됨

- **WHEN** 로그인 확인 단계의 결과가 로그인됨임
- **THEN** 다음 버튼이 활성화되고, 누르면 선택을 보관하고 작은 창으로 넘어간다

#### Scenario: 고른 에이전트의 훅 설치 실패

- **WHEN** 고른 Codex의 훅 설치가 실패함
- **THEN** 선택 단계에 Codex의 설치 실패와 이유가 보이고, 선택 단계의 다음 버튼은 에이전트와 모델이 골라졌으면 활성화된다

## ADDED Requirements

### Requirement: FR-START-008 로그인 확인 단계

로그인 확인 단계는 선택 단계에서 고른 에이전트와 실행 환경의 로그인 상태(FR-AGENT-009)를 확인해 보여 주어야 한다(SHALL). 이 단계에 들어올 때마다 새로 확인하고, 확인하는 동안에는 확인 중임을 보여 준다. 결과는 로그인됨(로그인 방식 포함), 로그인 안 됨, 확인 실패(이유 포함) 중 하나로 보인다. 화면에는 다시 확인 버튼이 있고, 확인 중에는 비활성화된다.

#### Scenario: 들어오면 확인

- **WHEN** 선택 단계에서 macOS의 Claude Code를 고르고 다음 버튼을 누름
- **THEN** 로그인 확인 단계에 확인 중이 보이고, 확인이 끝나면 macOS Claude Code의 로그인 상태가 보인다

#### Scenario: 에이전트를 바꾸고 다시 들어옴

- **WHEN** 로그인 확인 단계에서 이전으로 돌아가 Codex로 바꾸고 다시 다음 버튼을 누름
- **THEN** Codex의 로그인 상태를 새로 확인하고, 앞서 확인한 Claude Code의 결과는 보이지 않는다

#### Scenario: 확인 실패

- **WHEN** 로그인 확인이 시간 초과로 확인 실패가 됨
- **THEN** 확인 실패와 이유가 보이고 다시 확인 버튼이 활성화된다

#### Scenario: 다시 확인

- **WHEN** 결과가 로그인 안 됨인 상태에서 사용자가 터미널에서 로그인한 뒤 다시 확인 버튼을 누름
- **THEN** 로그인 상태를 새로 확인하고, 결과가 로그인됨으로 바뀌며 다음 버튼이 활성화된다

### Requirement: FR-START-009 로그인 안내

로그인 확인 결과가 로그인 안 됨이면, 로그인 확인 단계는 사용자가 터미널에서 직접 실행할 로그인 명령과 그 명령을 클립보드에 복사하는 버튼을 보여 주어야 한다(SHALL). 명령은 Claude Code는 `claude auth login`, Codex는 `codex login`이다. WSL 항목이면 그 배포판의 터미널에서 실행하라는 안내와 배포판 이름을 함께 보여 준다. 앱은 로그인 명령을 실행하지 않는다.

#### Scenario: Claude Code 로그인 안 됨

- **WHEN** macOS의 Claude Code가 로그인 안 됨으로 확인됨
- **THEN** 터미널에서 `claude auth login`을 실행하라는 안내와 복사 버튼이 보인다

#### Scenario: 명령 복사

- **WHEN** 로그인 안내의 복사 버튼을 누름
- **THEN** 클립보드에 로그인 명령이 복사되고, 복사되었음이 보인다

#### Scenario: WSL Codex 로그인 안 됨

- **WHEN** WSL `Ubuntu`의 Codex가 로그인 안 됨으로 확인됨
- **THEN** WSL `Ubuntu` 터미널에서 `codex login`을 실행하라는 안내와 복사 버튼이 보인다

#### Scenario: 로그인됨이면 안내 없음

- **WHEN** 로그인 상태가 로그인됨으로 확인됨
- **THEN** 로그인 명령 안내와 복사 버튼은 보이지 않는다

### Requirement: FR-START-010 모델 목록 다시 불러오기

선택 단계는 고른 에이전트의 모델 목록을 다시 조회하는 버튼을 보여 주어야 한다(SHALL). 누르면 FR-START-007의 방식으로 그 에이전트의 목록만 새로 조회하고, 조회가 끝나면 고른 모델이 새 목록에도 있으면 그대로 두고 없으면 FR-START-004대로 다시 고른다. 에이전트를 고르지 않았거나 그 에이전트의 목록을 불러오는 중이면 버튼은 비활성화된다.

#### Scenario: 목록 다시 불러오기

- **WHEN** macOS의 Claude Code와 `sonnet`을 고른 상태에서 다시 불러오기 버튼을 누름
- **THEN** 모델 선택지가 불러오는 중으로 보이고, 새 목록에 `sonnet`이 있으면 조회가 끝난 뒤에도 `sonnet`이 골라져 있다

#### Scenario: 불러오는 중 버튼 비활성화

- **WHEN** 고른 에이전트의 모델 목록을 불러오는 중임
- **THEN** 다시 불러오기 버튼은 비활성화된다

#### Scenario: 에이전트를 고르지 않음

- **WHEN** 선택 단계에서 에이전트가 골라지지 않음
- **THEN** 다시 불러오기 버튼은 비활성화된다
