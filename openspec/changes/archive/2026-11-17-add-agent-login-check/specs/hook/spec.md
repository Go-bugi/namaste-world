## ADDED Requirements

### Requirement: FR-HOOK-016 다시 설치

앱은 renderer가 다시 설치를 요청하면 보관한 감지 결과에서 설치됨인 항목에 훅 설치를 다시 하고, FR-HOOK-007의 보관한 결과를 새 결과로 바꿔야 한다(SHALL). 다시 설치는 FR-HOOK-002의 설치와 같은 규칙(기존 훅 보존, 권한 문제 처리 포함)을 따른다. 시작 설정 창의 훅 설치 단계에는 다시 설치 버튼이 있고, 설치가 진행 중인 동안(앱 시작 설치와 다시 감지 뒤 설치 포함) 이 버튼은 비활성화된다.

#### Scenario: 권한 문제를 고친 뒤 다시 설치

- **WHEN** Codex 설정 파일에 쓸 수 없어 설치가 실패했고, 사용자가 권한을 고친 뒤 다시 설치 버튼을 누름
- **THEN** Codex에 훅이 설치되고, 훅 설치 단계의 Codex 줄이 실패에서 성공으로 바뀐다

#### Scenario: 설치 중 버튼 비활성화

- **WHEN** 훅 설치가 진행 중임
- **THEN** 다시 설치 버튼은 비활성화되고, 설치가 끝나면 다시 활성화된다
