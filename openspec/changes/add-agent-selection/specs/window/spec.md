# Spec Delta

## Purpose

시작 설정 창에서 작은 창으로 넘어가는 동작과 앱 창의 크기와 위치를 정합니다. 모니터가 여러 개이거나 배율이 서로 달라도 창이 보이는 곳에 맞는 크기로 열리게 합니다.

## ADDED Requirements

### Requirement: FR-WINDOW-001 시작 설정 창에서 작은 창으로 전환

앱은 시작 설정 창의 다음 버튼이 눌리면 작은 창(label `main`)을 열고 시작 설정 창을 닫아야 한다(SHALL). 작은 창은 논리 크기 320×320이고, 제목 표시줄과 테두리가 없고 macOS와 Windows 모두에서 배경이 투명하며, 다른 창보다 항상 위에 뜬다. Windows 작업 표시줄과 macOS 독에는 앱이 보인다. 작은 창이 열린 뒤에 시작 설정 창을 닫아서, 전환하는 동안 열린 창이 하나도 없는 순간 때문에 앱이 종료되지 않게 한다.

#### Scenario: 다음을 누름

- **WHEN** 시작 설정 창에서 다음을 누름
- **THEN** 작은 창이 열리고 시작 설정 창은 사라지며, 앱은 계속 실행 중이다

#### Scenario: 작은 창 외형

- **WHEN** 작은 창이 열림
- **THEN** 창에는 제목 표시줄과 테두리가 없고, 3D 요소 바깥으로 뒤의 화면이 비쳐 보이며, 다른 앱 창을 눌러도 작은 창이 그 위에 남는다
- **AND** Windows 작업 표시줄과 macOS 독에 앱 아이콘이 보인다

#### Scenario: 다음을 두 번 빠르게 누름

- **WHEN** 다음 버튼을 연달아 두 번 누름
- **THEN** 작은 창은 하나만 열린다

### Requirement: FR-WINDOW-002 작은 창의 시험용 3D 요소

작은 창은 시험용 3D 요소 하나를 보여 주어야 한다(SHALL). 3D 요소는 계속 움직여서 렌더링이 멈추지 않았는지 눈으로 확인할 수 있다. 3D 요소가 준비되기 전에는 빈 화면 대신 불러오는 중임을 보여 준다.

#### Scenario: 작은 창이 열림

- **WHEN** 작은 창이 열림
- **THEN** 투명한 배경 위에 계속 움직이는 3D 요소 하나가 보인다

### Requirement: FR-WINDOW-003 같은 모니터에 열기

앱은 작은 창을 시작 설정 창이 있던 모니터의 작업 영역 오른쪽 아래 구석에 열어야 한다(SHALL). 창의 오른쪽과 아래쪽은 작업 영역 가장자리에서 논리 단위 16만큼 떨어진다. 시작 설정 창이 두 모니터에 걸쳐 있으면 창 중심이 있는 모니터를 쓰고, 그 모니터를 알 수 없으면 주 모니터를 쓴다.

#### Scenario: 보조 모니터에서 진행

- **WHEN** 모니터가 두 개이고 시작 설정 창을 보조 모니터로 옮긴 뒤 다음을 누름
- **THEN** 작은 창이 보조 모니터 작업 영역의 오른쪽 아래 구석에 열린다

#### Scenario: 두 모니터에 걸침

- **WHEN** 시작 설정 창이 두 모니터에 걸쳐 있고 창 중심이 오른쪽 모니터에 있음
- **THEN** 작은 창이 오른쪽 모니터에 열린다

### Requirement: FR-WINDOW-004 모니터 배율이 달라도 같은 크기

앱은 창 크기와 위치를 모니터 배율(DPI)과 무관한 논리 단위로 정해야 한다(SHALL). 배율이 다른 모니터에 열어도 창이 보이는 크기는 같다.

#### Scenario: 배율이 다른 보조 모니터

- **WHEN** 주 모니터 배율이 200%, 보조 모니터 배율이 100%이고 작은 창을 보조 모니터에 엶
- **THEN** 작은 창은 주 모니터에 열었을 때와 같은 논리 크기로 열리고, 일부가 잘리거나 두 배로 커지지 않는다

### Requirement: FR-WINDOW-005 보이는 화면 안에 배치

앱은 창을 열 때 창 전체가 그 모니터의 작업 영역(작업 표시줄, 독, 메뉴 막대를 뺀 영역) 안에 들어오게 위치를 정해야 한다(SHALL). 창이 작업 영역보다 크면 작업 영역 크기로 줄인다.

#### Scenario: 작업 표시줄 위

- **WHEN** Windows 작업 표시줄이 화면 아래에 있음
- **THEN** 작은 창은 작업 표시줄에 가려지지 않고 그 위 16만큼 떨어진 곳에 열린다

#### Scenario: macOS 독이 오른쪽에 있음

- **WHEN** macOS 독이 화면 오른쪽에 있음
- **THEN** 작은 창은 독에 가려지지 않고 독 왼쪽 16만큼 떨어진 곳에 열린다

#### Scenario: 작은 모니터

- **WHEN** 창 크기가 모니터 작업 영역보다 큼
- **THEN** 창은 작업 영역 크기로 줄어 그 안에 열린다

### Requirement: FR-WINDOW-006 열려 있는 창 다시 보이기

앱은 사용자가 앱을 다시 불러낼 때(macOS 독 아이콘 클릭, 앱 다시 실행) 그 시점에 쓰는 창을 보여 주어야 한다(SHALL). 작은 창으로 넘어간 뒤면 작은 창을, 그 전이면 시작 설정 창을 보여 준다.

#### Scenario: 작은 창을 닫은 뒤 독 아이콘 클릭

- **WHEN** macOS에서 작은 창으로 넘어간 뒤 작은 창을 닫고 독 아이콘을 누름
- **THEN** 작은 창이 다시 보이고 시작 설정 창은 열리지 않는다

### Requirement: FR-WINDOW-007 작은 창 닫기

앱은 작은 창이 닫히면 macOS에서는 창만 숨기고 앱을 계속 실행해야 하고, Windows에서는 앱을 종료해야 한다(SHALL). 작은 창에는 닫기 버튼이 없으므로 macOS는 Cmd+W, Windows는 Alt+F4로 닫는다.

#### Scenario: macOS에서 닫기

- **WHEN** macOS에서 작은 창에 Cmd+W를 누름
- **THEN** 작은 창이 사라지고 앱은 계속 실행 중이며, 독 아이콘을 누르면 작은 창이 다시 보인다

#### Scenario: Windows에서 닫기

- **WHEN** Windows에서 작은 창에 Alt+F4를 누름
- **THEN** 앱이 종료된다

### Requirement: FR-WINDOW-008 작은 창 끌어 옮기기

작은 창은 창 안 아무 곳이나 마우스로 끌면 따라 움직여야 한다(SHALL). 3D 요소 바깥의 투명한 부분도 작은 창이 클릭을 받으며, 그 클릭은 뒤의 앱으로 넘기지 않는다. 옮긴 위치는 저장하지 않으며, 다음에 작은 창을 새로 열 때는 FR-WINDOW-003대로 연다.

#### Scenario: 끌어서 옮김

- **WHEN** 작은 창의 3D 요소 위를 누른 채 왼쪽 위로 끎
- **THEN** 작은 창이 마우스를 따라 왼쪽 위로 옮겨진다

#### Scenario: 투명한 부분을 끎

- **WHEN** 작은 창에서 3D 요소가 없는 투명한 구석을 누른 채 끎
- **THEN** 작은 창이 마우스를 따라 옮겨지고, 뒤에 있던 앱은 클릭을 받지 않는다

#### Scenario: 다른 모니터로 옮김

- **WHEN** 작은 창을 배율이 다른 옆 모니터로 끌어 옮김
- **THEN** 작은 창은 옮긴 모니터에서도 같은 논리 크기로 보인다

### Requirement: SC-WINDOW-001 전환 시간

다음 버튼을 누른 뒤 1초 안에 작은 창이 화면에 보여야 한다(MUST). 3D 요소가 그려지는 시간은 포함하지 않는다.

#### Scenario: 전환

- **WHEN** 시작 설정 창에서 다음을 누름
- **THEN** 1초 안에 작은 창이 보인다
