# Main Project Specification

구현되어 머지된 기능의 스펙을 하나로 합친 문서입니다. 기능을 머지하기 전에 `/speckit-archive-run <기능 디렉터리>`가 `specs/<기능>/spec.md`의 내용을 아래 섹션에 합칩니다. 손으로 고치지 않습니다.

- 섹션 구조와 순서는 이 뼈대를 따릅니다. archive는 기존 섹션 안에서만 합칩니다.
- 각 항목의 `[Source: specs/<기능>/spec.md -> <ID>]`는 그 항목이 어느 기능 spec에서 왔는지 가리킵니다.
- 기능 요구사항은 `#### <도메인 코드> <영역>` 하위 제목으로 묶습니다. 도메인 코드는 constitution의 "Spec Conventions"에 있습니다.
- 지워진 요구사항 ID는 `changelog.md`의 `RETIRED:` 줄에 남고 다시 쓰지 않습니다.
